# PixelRevive - AI-Based Restoration of Degraded Images

Joint denoising + 2x super-resolution network (`RestoreNet`, NAFNet-style
encoder-decoder) for restoring degraded grayscale semiconductor images.
KLA hackathon submission.

This README alone is enough to clone this repo and run inference.

## Repository structure

```
<team_name>/
├── README.md                    # this file
├── run.py                       # REQUIRED evaluation script
├── model.py                     # RestoreNet architecture (imported by run.py + train.py)
├── requirements.txt              # pip dependencies
├── train.py                       # training script -- reproduces training from scratch
├── losses.py                       # loss functions used by train.py
├── dataset.py                       # paired GT/LR dataset loader used by train.py
├── models/
│   └── restorenet_final.pt           # trained weights (see note below on size / LFS)
├── restored_test_outputs/              # our model's actual output on the test set
│   └── *.npy
├── eval.py                              # optional: earlier PNG-only inference script
├── compute_metrics.py                    # optional: SSIM/PSNR/LPIPS on our own held-out split
└── CHANGES.md                              # architecture/training design notes vs. the first version
```

## Setup

```
pip install -r requirements.txt
```
This is the only step that may need internet access. Running `run.py` never
needs internet, an API key, or any extra download - weights load from the
local `models/` folder and the device is auto-detected (CUDA if available,
else CPU).

## Evaluation

```
python run.py <input_dir> <output_dir>
```
- Reads every `.npy` file in `<input_dir>`.
- Creates `<output_dir>` automatically if it doesn't exist.
- Writes one restored `.npy` file per input, same filename, to `<output_dir>`.
- Runs as-is, no manual edits needed.

Optional flags: `--weights <path>` (default `models/restorenet_final.pt`),
`--device auto|cuda|cpu` (default `auto`).

**Input:** grayscale `.npy`, shape `(H,W)`, `(H,W,1)`, or `(1,H,W)`. Integer
arrays assumed `[0,255]`; float arrays assumed already normalized to roughly
`[0,1]` (may exceed 1.0 -- expected, from speckle noise).

**Output:** `float32` `.npy`, shape `(2H, 2W)`, values clipped to `[0,1]`,
guaranteed free of NaN/Inf.

## Training (reproduces our model from scratch)

```
python train.py \
  --gt_dir /path/to/train/GT --lr_dir /path/to/train/NoisyLR \
  --out_dir checkpoints \
  --epochs_stage1 15 --epochs_stage2 40 \
  --batch_size 16 --crop_lr 128
```
- `--gt_dir` / `--lr_dir` must point at the two folders inside the unzipped
  training data - check the actual folder names first, this script does not
  guess them.
- Two-stage training: Stage 1 pretrains a denoiser, Stage 2 fine-tunes the
  full denoise+SR pipeline end-to-end with the combined
  Charbonnier+SSIM+perceptual+edge+range loss (see `losses.py`).
- Needs a GPU (Colab/Kaggle recommended) - CPU will run but is very slow.
- Writes `checkpoints/restorenet_final.pt` (EMA weights - what `run.py`
  loads) plus intermediate/best checkpoints and `test_split.json` (the
  held-out split, for `compute_metrics.py`).
- All CLI flags and defaults: `python train.py --help`. Full rationale for
  every architecture/loss/training choice is in `CHANGES.md`.

To use a freshly trained checkpoint for evaluation, copy it into place:
```
cp checkpoints/restorenet_final.pt models/restorenet_final.pt
```

## Trained model weights

`models/restorenet_final.pt` - final checkpoint (EMA weights), loadable
directly by `run.py` and `train.py`'s config format
(`{"model_state": ..., "config": {"base_ch", "n_res", "scale"}}`). ~14MB,
committed directly - no Git LFS needed.

## Restored test outputs

`restored_test_outputs/` contains this model's actual `.npy` outputs on the
KLA test set, generated by running:
```
python run.py <path_to_KLA_test_set> restored_test_outputs
```

## Notes

- `run.py` is the required, standalone evaluation script not a notebook,
  runs as-is, no manual edits.
- `eval.py` is an earlier PNG-only inference script, superseded by `run.py`.
- For our own SSIM/PSNR/LPIPS numbers on a held-out split (not part of the
  grading path), see `compute_metrics.py` (needs `scikit-image` + `lpips`,
  not required for `run.py`).
